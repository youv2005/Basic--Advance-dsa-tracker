# AI-assisted concept learning

The roadmap now includes a lightweight learning layer for every concept.

- **Quick notes**: short explanation, key points, prerequisite and complexity/target.
- **Learn with AI**: choose ChatGPT, Gemini, Claude, Perplexity or Microsoft Copilot.
- The app copies a context-aware tutoring prompt and opens the selected provider in a new tab.
- **Copy prompt only** lets a learner use any other AI service they prefer.

No AI API key or backend is required for this feature. The learner controls which AI provider they use.
